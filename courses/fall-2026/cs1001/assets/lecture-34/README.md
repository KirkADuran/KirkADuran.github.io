This is a survey lecture: emphasize the general data pipeline and the capstone. `b` and `+` modes and destructive directory deletion are deliberately not taught in depth.

## Notes

`csv.reader` returns strings; convert numeric fields explicitly. JSON saves data such as lists/dicts, not user-defined Python class code; reconstruct the instances with constructors. Opening files with `w` truncates their contents. Caesar shifts are educational only, not secure encryption.
